# RNA-seq quantification on PDX graft samples (nf-core/rnaseq 3.12)

## `nf_core_3.12`

Once the `graft` FASTQ files are generated by Xenome (cf. [MAPPYACTS_RMO_QC/PDX/01_Xenome](https://github.com/gustaveroussy/MAPPYACTS_RMO_QC/tree/main/PDX/01_Xenome)), they are used as input for quantification and QC with the nf-core/rnaseq pipeline (STAR alignment + Salmon quantification, QC report, etc.), version [3.12](https://nf-co.re/rnaseq/3.12.0/)

### 1. Create SampleSheet

```bash
python createSP.py
```

### 2. Run nf-core pipeline

Nextflow runs from a dedicated conda environment, defined in `environment.yaml`. To create it:
 
```bash
conda env create -f environment.yaml
```

Then, run the pipeline : 

```bash
sbatch run_nfcore.sh
```

> `nextflow.config` and `base.config` have been adapted specifically for nf-core/rnaseq 3.12 to run on the Flamingo SLURM cluster (partitions, resource limits, and Singularity profile).
